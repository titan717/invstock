## ✨ A safer place to learn trading concepts

InvStock is a **stock market simulator** built around practice and experimentation. Explore a simulated investing experience, try different decisions, and learn how trading mechanics work without placing real trades.

  <a href="https://invstock-mu.vercel.app/"><strong>Launch the simulator ↗</strong></a>

## 🎯 What InvStock is

- **Educational simulation:** practice with simulated quotes, options, and news.
- **Mobile-first experience:** designed to work comfortably on smaller screens.
- **Interactive product:** experiment with market-style decisions in a game-like environment.
- **Built for learning:** explore trading concepts without connecting a brokerage account.

> **Important:** All quotes, options, and news in InvStock are simulated. InvStock is an educational trading game, not a brokerage, investment platform, or live market-data service. It does not provide financial advice.

## 🚀 Run locally

**Requirements:** Node.js and npm.

```bash
git clone https://github.com/titan717/invstock.git
cd invstock
npm install
npm run dev
```

Open the local URL printed by the development server.

## 🧪 Verify the project

```bash
npm test
npm run lint
npm run build
```

- `npm test` — simulator behaviour tests
- `npm run lint` — TypeScript check
- `npm run build` — production build
