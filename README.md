# InvStock

InvStock is a mobile-first stock-market simulator built with Next.js, React, TypeScript, Tailwind CSS, Lucide React and Recharts.

## Development

- `npm install`
- `npm run dev`

## Verification

- `npm test` — simulator behavior tests
- `npm run lint` — TypeScript check
- `npm run build` — production build

All quotes, options and news are simulated. This is an educational trading game, not a brokerage or live market-data service.
